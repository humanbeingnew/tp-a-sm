# ROBOTIS Humanoid A-Type Simulator V5
이번 버전은 V4의 핵심 문제였던 **초기값을 각도 0의 기준으로 직접 회전시키는 방식**을 제거했습니다.

- 공식 A-Type init 값을 그대로 보관
- 초기 자세에서는 모델 자체가 기준 자세이며, 각 모터의 변화량은 `현재값 - init값`으로 적용
- 512는 별도의 중앙값으로 유지
- 18개 모터 전부 입력 가능
- 6 DOF × 2 legs + 3 DOF × 2 arms 구조
- 정면 / 초기 자세 / 전체 512 / 배열 복사

공식 문서에서 A-Type은 18개 AX-12+와 해당 init 값 및 Mirror ID를 정의합니다.
현재 3D 파트는 자체 검증용 모델이며 실제 R+ Motion의 `.rbt` CAD/변환행렬을 그대로 복제한 것은 아닙니다.
