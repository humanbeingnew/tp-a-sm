# Humanoid A-Type Online Simulator

GitHub Pages에서 바로 올릴 수 있는 정적 웹 시뮬레이터입니다.

## 실행
- `index.html`을 브라우저에서 열거나
- GitHub 저장소에 업로드 후 Settings → Pages에서 배포

## 기능
- 3D 휴머노이드 형태 표시
- 18개 모터 Position(0~1023) 조작
- 초기 자세 복귀
- 카메라 확대/높이 조절
- 마우스로 로봇 회전
- 기본 입력값 검증

## 참고
이 프로젝트는 모션 제작/검사용 독립 시뮬레이터이며 실제 로봇의 조립 방향, 오프셋 및 안전 한계와 동일하다고 가정하지 않습니다.
